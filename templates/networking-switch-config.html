Basic switch setup

Switch
enable
configure terminal
hostname SW1
enable secret ChangeMe123
service password-encryption
banner motd #Authorized access only#
interface vlan 1
 ip address 192.168.1.2 255.255.255.0
 no shutdown
exit
ip default-gateway 192.168.1.1
line console 0
 password cisco
 login
exit
line vty 0 4
 password cisco
 login
end
copy running-config startup-config

VLANs and access ports

Switch
vlan 10
 name SALES
vlan 20
 name IT
interface range fastethernet 0/1 - 8
 switchport mode access
 switchport access vlan 10
interface gigabitethernet 0/1
 switchport mode trunk
end

Router interfaces

Router (try it in the simulator)
enable
configure terminal
hostname R1
interface gigabitethernet 0/0
 description LAN
 ip address 192.168.1.1 255.255.255.0
 no shutdown
interface gigabitethernet 0/1
 description Link to R2
 ip address 10.0.0.1 255.255.255.252
 no shutdown
end

Static routes

Router (try it in the simulator)
configure terminal
ip route 192.168.2.0 255.255.255.0 10.0.0.2
end
show ip route

Remember the return route: R2 also needs ip route 192.168.1.0 255.255.255.0 10.0.0.1, otherwise replies never come back.
